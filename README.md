# RUNUP

Plan de entrenamiento 5K sub-20 (carrera: 15 de noviembre de 2026).

Abre `index.html` en el navegador: cada sesión tiene su check y un campo para apuntar tiempos. El progreso se guarda en el navegador.

## Desplegar en Vercel / instalar en el iPhone

Vercel ejecuta `node build.mjs`, que genera `dist/` con la página, el icono y el manifest.
En el iPhone: abre la URL en Safari → Compartir → "Añadir a pantalla de inicio".
